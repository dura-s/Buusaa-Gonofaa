# Buusaa Gonofaa Oromiyaa - Adama Branch

Branch website for Buusaa Gonofaa Oromiyaa (Adama Branch), providing member information on savings accounts, agricultural credit, weather-indexed crop insurance, and community support funds.

## Features

- **Trilingual Support**: Afaan Oromoo, Amharic, and English with language switcher.
- **Service Information**: Savings, farming input loans, and index-based crop insurance.
- **Community Updates**: Reports and photography from branch assemblies and grain distribution events.
- **Contribution Records**: Deposit recording and transaction reference submissions backed by Firebase Firestore.
- **Contact Inquiries**: Direct inquiry form and office hours for the central Adama office.

## Development

```bash
npm install
npm run dev
```

Runs on `http://localhost:3000`.

## Production Build

```bash
npm run build
npm start
```
